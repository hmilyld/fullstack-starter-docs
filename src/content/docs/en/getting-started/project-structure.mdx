## The Scaffold Itself

```
fullstack-starter/
├── src/
│   ├── index.ts              # CLI entry: interactive selection of frontend / backend / project name
│   └── generator.ts          # Generator: copy templates + generate config and script files
├── templates/
│   ├── base/                 # Shared files (.gitignore)
│   ├── frontend-react/       # React frontend template
│   ├── frontend-vue/         # Vue frontend template
│   ├── backend-python/       # FastAPI backend template
│   └── backend-java/         # Spring Boot backend template
├── package.json
└── tsconfig.json
```

The files under `templates/` are exactly what users end up with; the generator only copies templates and dynamically generates `dev.sh`, `build.sh`, `Dockerfile`, `docker-compose.yml`, `.dockerignore`, `nginx.conf`, and each project's README.

## The Generated Project

```
my-project/
├── frontend/                 # Frontend project
├── backend/                  # Backend project
├── dev.sh                    # Development script: start / stop / restart / install
├── build.sh                  # Build script: frontend build + backend check
├── Dockerfile                # Single image: frontend build + backend + Nginx
├── docker-compose.yml        # Docker orchestration
├── .dockerignore             # Docker build exclusions
├── nginx.conf                # Nginx config: static files + /api reverse proxy
└── README.md                 # Project documentation
```

## Key Files

| File | Purpose |
| --- | --- |
| `dev.sh` | Development script; installs dependencies and starts frontend and backend together |
| `build.sh` | Frontend build + backend code check |
| `Dockerfile` | Multi-stage build producing a single image with Nginx and the backend |
| `nginx.conf` | Listens on 5173, serves frontend static files, and proxies `/api/` to the backend |
| `frontend/vite.config.ts` | Proxies `/api` to `localhost:8088` during development |

For more detail, see [Frontend Structure](/en/generated/frontend/), [Python Backend](/en/generated/backend-python/), and [Java Backend](/en/generated/backend-java/).
