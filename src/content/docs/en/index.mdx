## Six combinations, one system

Frontend and backend combine freely: all six share one API contract, one permission catalog and one visual spec.

| | Python · FastAPI | Java · Spring Boot |
| --- | --- | --- |
| **React 19** | React + Vite + Tailwind v4 + shadcn/ui ／ FastAPI + SQLAlchemy 2 | React + Vite + Tailwind v4 + shadcn/ui ／ Spring Boot 3 + JPA |
| **Vue 3** | Vue 3 + Vite + Tailwind v4 + shadcn-vue ／ FastAPI + SQLAlchemy 2 | Vue 3 + Vite + Tailwind v4 + shadcn-vue ／ Spring Boot 3 + JPA |
| **Svelte 5** | SvelteKit 3 + Vite + Tailwind v4 + shadcn-svelte ／ FastAPI + SQLAlchemy 2 | SvelteKit 3 + Vite + Tailwind v4 + shadcn-svelte ／ Spring Boot 3 + JPA |

Swap the frontend without touching the backend, or the backend without touching the frontend: all three frontends stay in sync down to interaction details, and both backends run the same contract tests.

## What you get

Not an empty shell: authentication, RBAC, menu management, audit logs, data management and a dashboard work out of the box. Sign in with `admin / 123456`.
