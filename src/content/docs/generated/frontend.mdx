React 与 Vue 模板采用同一套功能划分：按业务域拆分 API 与类型，页面放在 `pages/`，共享技术代码放在 `components/` 与 `lib/`（Vue 为 `stores/`、`composables/`）。

## 请求层

前端 HTTP 层是一个轻量的原生 `fetch` 封装，**不使用 axios**。它分成两层：

- `src/api/http.ts` —— 基础设施：`BASE_URL`、查询串拼接、鉴权头、`Content-Disposition` 文件名解析、JSON 请求与原始请求。只被 `client.ts` 使用。
- `src/api/client.ts` —— 对外的 `apiClient`：`get` / `post` / `put` / `delete` / `download` / `upload` / `getWithHeaders`。

行为约定：

- 基础地址固定为 `/api`，开发时由 Vite 代理到 `localhost:8088`。
- 自动附加 `Authorization: Bearer <token>`。
- 收到 **401** 时清除登录状态并跳转登录页。
- `get` / `post` / `put` / `delete` 统一返回 `{ code, message, data }`，网络与 HTTP 错误都不抛异常，调用方检查 `code`。
- `download` / `upload` / `getWithHeaders` 走原始请求，失败时抛异常，并保留响应头（导出密码、任务 token 等）。

各业务域的调用拆分在 `src/api/` 下：`auth.ts`、`user.ts`、`role.ts`、`permission.ts`、`menu.ts`、`system.ts`、`dashboard.ts`、`ai-model.ts`、`audit-log.ts`、`data-management.ts`。请求体与响应类型统一放在 `src/types/` 对应的业务域文件里，`api/` 只保留调用函数。

### API 层规则

1. **只放请求定义**：`api/` 下的文件只导出调用函数，不写格式化、DOM 操作、toast 或业务编排。
2. **类型归 `types/`**：请求体、响应体、查询参数类型一律放在 `src/types/<域>.ts`，`api/` 用 `import type` 引入。
3. **域内闭环**：业务域文件之间不互相 import；跨域共享的能力放到 `lib/`。
4. **升级规则**：当某个域的文件超过约 150 行，或该域需要第二个文件时，才把 `api/<域>.ts` 升级为 `api/<域>/index.ts` + 同目录子文件；其余域保持平铺。不要在域数量还少的时候提前嵌套。

## 路由与鉴权

- 路由使用 `react-router`（React）或 `vue-router`（Vue）。
- `ProtectedRoute`（Vue 为路由守卫）只校验**是否已登录**；未登录跳转登录页。
- 侧边栏调用 `GET /api/menus/navigation` 动态加载；后端按当前用户权限过滤，分组内没有可见菜单时整组隐藏。
- 菜单顺序、分组、路由和图标来自 `menu_groups` / `menu_items`，不再硬编码在 `AppSidebar` 中。
- **真正的访问控制在后端**：前端隐藏菜单只是体验优化，后端仍按权限点拒绝越权请求。

安全提示：不要只依赖前端路由做权限判断，服务端才是权威。详见[权限系统](/features/rbac/)。

## 状态管理

| | React | Vue |
| --- | --- | --- |
| 认证状态 | `lib/auth-context.tsx` | `stores/auth.ts`（Pinia） |
| 站点配置 | `lib/site-config.tsx` | `stores/site-config.ts` |
| 主题 | `components/theme-provider.tsx` | `stores/theme.ts` |

站点配置来自公开接口 `GET /api/public/config`，用于登录页显示站点名称、维护提示，以及判断是否开放注册。

## 界面约定与主题

- 三端自适应：`< 768px` 使用卡片列表与抽屉导航，`768–1023px` 使用图标栏，`>= 1024px` 使用完整侧边栏。
- 提供明暗主题切换（`ThemeToggle`），偏好会被持久化。
- 两端都基于 Tailwind CSS v4 + shadcn：React 用 shadcn/ui（Radix UI），Vue 用 shadcn-vue（Reka UI）；表单、表格、分页、确认删除等共享组件位于 `components/shared/`。

## 新增一个页面

以 React 为例：

1. 在 `src/pages/` 下新建页面组件。
2. 在 `router.tsx` 注册路由。
3. 为页面定义权限码，并在「菜单与权限」页创建或同步菜单项、设置路由和图标，再给角色授权。
4. 在 `src/api/` 与 `src/types/` 下补充该业务域的调用与类型。

Vue 对应修改 `pages/`、`router/index.ts`、`api/`、`types/`，菜单配置仍在后台完成。
