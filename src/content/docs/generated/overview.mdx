四种组合共享同一套功能、接口约定与响应格式，因此可以按团队熟悉的技术栈自由选择。

## 组合矩阵

| | Python (FastAPI) | Java (Spring Boot) |
| --- | --- | --- |
| **React** | React 19 + Vite + shadcn/ui · FastAPI async | React 19 + Vite + shadcn/ui · Spring Boot 3.2 |
| **Vue** | Vue 3 + Vite + shadcn-vue · FastAPI async | Vue 3 + Vite + shadcn-vue · Spring Boot 3.2 |

## 前端技术栈

| 组件 | React 模板 | Vue 模板 |
| --- | --- | --- |
| 框架 | React 19 | Vue 3.5+（Composition API） |
| 构建 | Vite | Vite |
| 语言 | TypeScript | TypeScript |
| 样式 | Tailwind CSS v4 + shadcn/ui（Radix UI） | Tailwind CSS v4 + shadcn-vue（Reka UI） |
| HTTP | 原生 fetch 封装（401 自动登出） | 原生 fetch 封装（401 自动登出） |
| 路由 | react-router v7 | vue-router v5 |
| 状态 | React Context（`lib/`） | Pinia（`stores/`） |
| PWA | `vite-plugin-pwa` | `vite-plugin-pwa` |
| 图标 | lucide-react | `@lucide/vue` |

## 后端技术栈

| 组件 | Python 模板 | Java 模板 |
| --- | --- | --- |
| 框架 | FastAPI | Spring Boot 3.2 |
| ORM | SQLAlchemy 2.0（async） | Spring Data JPA |
| 数据库 | SQLite（aiosqlite，Alembic 迁移） | SQLite 文件（`./data/app.db`，Flyway 迁移） |
| 认证 | PyJWT + bcrypt（登出即失效） | Sa-Token（uuid 风格令牌）+ BCrypt |
| 密钥 | 环境变量 `JWT_SECRET_KEY`（弱密钥拒绝启动） | 无需密钥（服务端会话令牌） |
| 接口文档 | 内置 Swagger `/docs` | 内置 Swagger `/docs`（SpringDoc） |
| 契约测试 | `pytest`（32 条） | `mvn test`（28 条） |

:::caution[令牌不通用]
Python 使用 JWT，Java 使用 Sa-Token 的 UUID 令牌，两者格式不同、互不兼容。切换后端时前端需要重新登录，已签发的令牌无效。
:::

## 行为差异

两套后端的功能、权限模型与接口契约完全一致。实现层面的差异：

- **错误表达**：两栈都在业务失败时抛领域异常，由统一处理器映射为 `{ code: -1, message, data: null }`；`data` 键始终存在。
- **启动初始化**：Python 先执行 Alembic 迁移，再写入种子数据并同步权限/菜单；Java 由 Flyway 迁移，再依次执行权限和菜单同步任务。
- **令牌吊销**：Python 通过递增 `users.token_version` 使令牌失效；Java 通过 `StpUtil.logout(userId)` 吊销服务端会话。
- **权限拦截返回**：两栈在无权限时都返回 403，并记录一条审计日志。

## 响应格式

除数据导出文件外，所有接口统一返回：

```json
{ "code": 0, "message": "success", "data": {} }
```

出错时 `code` 为 `-1`，`message` 为中文提示。分页数据统一为 `{ list, total, page, pageSize }`。详见 [API 接口](/reference/api/)。

`POST /api/data/export` 成功时返回 ZIP 文件；一次性密码在 `X-Export-Password` 响应头中返回。
