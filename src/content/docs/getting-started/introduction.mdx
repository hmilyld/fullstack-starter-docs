`create-fullstack-app` 是一个全栈应用脚手架。运行交互式命令行，选择前端与后端框架，它会在当前目录生成一个可直接开发、构建和部署的后台管理系统。

生成的项目不是空壳：登录注册、用户管理、角色权限、系统设置、AI 模型管理、审计日志和仪表盘都已内置。

## 能生成什么

- **前端二选一**：React 19（Vite + TypeScript + Tailwind CSS v4 + shadcn/ui，含 PWA）或 Vue 3（Vite + TypeScript + Tailwind CSS v4 + DaisyUI）。
- **后端二选一**：Python（FastAPI + SQLAlchemy async + SQLite）或 Java（Spring Boot 3.2 + JPA + SQLite/Flyway）。
- **认证内置**：登录、注册、登出；Python 走 JWT，Java 走 Sa-Token；含登录/注册速率限制与 401 自动登出。
- **完整后台**：用户、角色、权限、系统设置、AI 模型与预设、审计日志、仪表盘、个人中心。
- **部署就绪**：单个 Docker 镜像内含 Nginx 与后端，一条命令启动。

## 四种组合

| 前端 | 后端 | 说明 |
| --- | --- | --- |
| React | Python | Vite + shadcn/ui，FastAPI async |
| React | Java | Vite + shadcn/ui，Spring Boot + JPA |
| Vue | Python | Vite + DaisyUI + Pinia，FastAPI async |
| Vue | Java | Vite + DaisyUI + Pinia，Spring Boot + JPA |

四种组合实现同一套功能与接口约定，前后端行为一致，可按团队技术栈自由选择。详见[技术栈与组合](/generated/overview/)。

## 适合谁

- 需要快速搭建带权限体系的后台管理系统的团队。
- 希望在前端 React/Vue、后端 Python/Java 之间自由组合，而不想重复实现认证与权限的开发者。
- 需要一套可直接阅读、修改的完整代码，而不是黑盒框架的场景。

## 权限模型

接口鉴权基于**权限点（RBAC）**，而不是判断角色名称。默认角色：

- `admin`（管理员）：拥有全部权限。
- `user`（普通用户）：仅有 `dashboard`、`users`、`settings` 三个菜单查看权限。
- `pending_review`（待审核）：无任何权限。

注册的新账号根据系统设置的「人工审核」开关进入 `user` 或 `pending_review`。详见[权限系统](/features/rbac/)。
