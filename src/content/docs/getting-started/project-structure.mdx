## 脚手架自身

```
fullstack-starter/
├── src/
│   ├── index.ts              # CLI 入口：交互式选择前端 / 后端 / 项目名
│   └── generator.ts          # 生成器：复制模板 + 生成配置与脚本文件
├── templates/
│   ├── base/                 # 公共文件（.gitignore）
│   ├── frontend-react/       # React 前端模板
│   ├── frontend-vue/         # Vue 前端模板
│   ├── backend-python/       # FastAPI 后端模板
│   └── backend-java/         # Spring Boot 后端模板
├── package.json
└── tsconfig.json
```

`templates/` 下的文件就是用户最终拿到的文件；生成器只负责复制模板，并动态生成 `dev.sh`、`build.sh`、`Dockerfile`、`docker-compose.yml`、`.dockerignore`、`nginx.conf` 和各项目 README。

## 生成的项目

```
my-project/
├── frontend/                 # 前端项目
├── backend/                  # 后端项目
├── dev.sh                    # 开发脚本：start / stop / restart / install
├── build.sh                  # 构建脚本：前端构建 + 后端检查
├── Dockerfile                # 单镜像：前端构建 + 后端 + Nginx
├── docker-compose.yml        # Docker 编排
├── .dockerignore             # Docker 构建排除项
├── nginx.conf                # Nginx 配置：静态文件 + /api 反代
└── README.md                 # 项目说明
```

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `dev.sh` | 开发脚本，自动安装依赖并同时启动前后端 |
| `build.sh` | 前端构建 + 后端代码检查 |
| `Dockerfile` | 多阶段构建，产出含 Nginx 与后端的单镜像 |
| `nginx.conf` | 监听 5173，提供前端静态文件并反代 `/api/` 到后端 |
| `frontend/vite.config.ts` | 开发时将 `/api` 代理到 `localhost:8088` |

更详细的说明见[前端结构](/generated/frontend/)、[Python 后端](/generated/backend-python/)、[Java 后端](/generated/backend-java/)。
