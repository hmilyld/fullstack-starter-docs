## 四种组合，同一套系统

前端和后端可以任意搭配，四种组合共用一份接口契约、一套权限目录和一套视觉规范：

| | Python · FastAPI | Java · Spring Boot |
| --- | --- | --- |
| **React 19** | React + Vite + Tailwind v4 + shadcn/ui ／ FastAPI + SQLAlchemy 2 | React + Vite + Tailwind v4 + shadcn/ui ／ Spring Boot 3 + JPA |
| **Vue 3** | Vue 3 + Vite + Tailwind v4 + shadcn-vue ／ FastAPI + SQLAlchemy 2 | Vue 3 + Vite + Tailwind v4 + shadcn-vue ／ Spring Boot 3 + JPA |

所以换前端不用动后端，换后端不用改前端：两套前端保持像素级与交互级同步，两套后端通过同一组契约测试。

## 生成出来的是什么

不是空壳。认证、RBAC、菜单管理、审计、数据管理与仪表盘开箱即用，默认账号 `admin / 123456` 即可登录。
